Media crop — option comparison

Static mockups for discussion. Both options use only public Payload APIs. Colours and spacing approximate the Payload 4 admin; real implementation uses @payloadcms/ui components.

Option 1 — Native “Edit image” (crop + focal point)

Enable upload.crop: true. The ✂ toolbar icon becomes the only manual entry. Our ratio dialog stays only for the automatic pop-up on upload.

Cons

  • Two different crop UIs (upload pop-up vs native)
  • Preview still shows the original until saved

Option 2 — Our ratio-locked dialog for all cropping

✂ stays native for focal point only. A “Crop to ratio” button sits on the preview (detail page, via public filePreview slot) or in the left column (create page, where the preview cannot be replaced). Pending crops are previewed before Save.
