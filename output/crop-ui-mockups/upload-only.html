Media crop — only when an uploaded image has an unsupported ratio

No general crop feature. The dialog appears only for a newly selected image whose ratio is outside 1:1, 4:3, 3:2, 16:9, 9:16, 4:5 (1% tolerance). There is no crop button anywhere; ✂ in the toolbar stays Payload’s native “Edit image” for the focal point.

Unsupported ratio on uploadDialog opens automatically → Apply crop or Choose another file.
Supported ratio on uploadNo dialog, no crop entry. Save as uploaded.
Saved imageNo crop entry. To change the ratio, use Replace file — the same rules apply.
