Media crop — Option A: crop icon on the preview

The toolbar row stays native (🔗 ✂ ↗ ⬇). Our “Crop to ratio” icon sits on the preview header, directly below and right-aligned with the toolbar, using the same icon button style, tooltip and dialog flow. It is available for every saved image, including images that already have a supported ratio. The manual crop button in the left column is removed.

1 · Click ⧉Same icon style and tooltip as the toolbar icons.
2 · DialogRatio tabs, locked crop, live result — Payload dialog components.
3 · Apply cropPreview switches to the cropped view; a status chip appears; Save becomes active.
4 · SavePayload crops the original on the server; chip disappears; meta shows new size.

Flow 2 — New upload (create page)

The selected-file preview cannot be replaced, so there is no icon here and no left-column button. Unsupported ratios open the dialog automatically; supported images are saved as uploaded and can be re-cropped later with the icon.
