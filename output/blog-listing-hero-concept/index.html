渲染规则

  • Hero 只在 /blogs 与 /blogs/page/N 出现；分类页不读取。
  • 启用且有标题 → 渲染 Hero，替代默认 <h1>Blogs</h1>。
  • 未启用、无标题、Global 未保存 → 保持当前页面。
  • 无图时退化为文字横幅；Header theme 同时决定横幅底色与 Header 前景色。

数据流

Settings (Global, tag: global_settings)
 └ blog.listing.hero
     ↓ getCachedSettings()      depth 1
     ↓ getBlogListingHero()     → model | null
     ↓ <BlogListingHero />      固定模板 + HeaderThemeSync
保存 → revalidateTag('global_settings')

扩展方式

  • 新的列表页内容：在 blog.listing 中 Hero 之后追加字段组。
  • 详情页内容：新增 blog.article 分组（如 “More to read” 标题）。
  • 其他业务：在 Settings 中新增 tab（如 Case Studies）。
