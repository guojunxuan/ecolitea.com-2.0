# Blog 分类文字导航

用户确认按参考图将分类按钮改为文字导航，并隐藏文章数量。分类仍由 Payload Blog Categories 提供；数量只用于过滤空分类，不在导航中显示。

桌面导航整行右对齐，使用无背景、无边框、无圆角的文字链接。`/blogs` 默认选择 All，分类页选择对应分类；选中项文字更突出，并始终保留固定的 2px 下划线。另一条 2px 下划线使用 Header 的快速 ease 动效，随其他项的 Hover 或键盘聚焦移动并匹配链接宽度，移出且无聚焦项时隐藏；选中项的固定线不移动。点击链接才切换分类。

移动端使用 Blog 加箭头的原生 details 下拉面板。展开后所有非空分类及 All 纵向排列，选中分类标记当前状态；点击链接、Esc 或点击外部收起，Esc 将焦点返回触发器。面板覆盖下方列表并可在内容过长时内部滚动。桌面布局换行后，Hover 线同时更新横纵位置。尺寸和字体加载触发重新测量；遵循 reduced-motion。服务端 HTML 和无 JavaScript 情况保留选中项静态线和原生下拉功能。客户端边界限制在桌面动效组件和移动端下拉组件。

验证覆盖隐藏数字、默认 All、Hover 不改变当前项、移出隐藏 Hover 线、键盘聚焦、路由变化和移动面板打开/关闭，更新现有 E2E 断言对应的新入口。后台结构和数据模型无需修改。
