# Header 优化设计

## 目标与边界

在保留当前 Payload Header 内容、导航数据和 Block 模型的前提下，将 Header 优化为可上线使用的品牌导航。Header 固定覆盖在视口顶部，不为页面内容预留高度；后续页面开发时，由页面决定内容延伸到 Header 后方或增加顶部留白。本轮只实现浅色体系，保留现有 `1170px` 精确断点，不新增 Payload schema 或平板专用导航。

外部链接遵循 Payload 的 `newTab` 配置。Rich Card 暂时维持一个 Block 对应一张卡片，不增加相邻 Block 自动分组。

## Header 状态

Desktop 页面顶部且菜单关闭时，Header 完全透明，Logo、导航和图标使用黑色。页面滚动超过 `30px` 后，Header 切换为约 90% 白色，并增加低对比度底边线和轻阴影。Mega Menu 打开时，无论页面是否滚动，Header 都使用约 90% 白色。Header 始终固定显示，不实现滚动隐藏。

Mobile 页面顶部且菜单关闭时 Header 完全透明；滚动超过 `30px` 后使用 100% 实体白色。菜单打开后，Header 和菜单面板都使用 100% 实体白色，不使用磨砂或页面遮罩。关闭菜单后，页面在顶部则恢复透明，已滚动则保持实体白色。

## 桌面一级导航

Header 使用 Logo、一级导航、工具区三段式布局。Logo 固定在左侧；Search 和 `Shop Insta360` 固定在右侧；只有一级导航参与横向滚动。

一级导航保持单行、固定字号、固定间距和 `white-space: nowrap`。外层使用 `overflow: hidden`，内部隐藏滚动条。空间不足时初始滚动到最右端，优先显示右侧菜单；左箭头查看前面的菜单。箭头固定在导航两侧，仅在溢出时显示；禁用状态保留尺寸并降低透明度。点击一次滚动到相邻完整菜单项。键盘聚焦到隐藏项时，将其完整滚入视野。两侧使用窄幅白色渐隐提示隐藏内容。

桌面一级菜单都不显示下拉箭头。纯 Dropdown 点击文字打开或关闭 Mega Menu。Hybrid 悬浮文字时打开 Mega Menu，点击文字直接跳转；键盘聚焦后按 `ArrowDown` 打开下拉内容。

所有菜单共用一条 Header 底部指示线。指示线高 `2px`、带圆角，覆盖整个菜单项点击区域但不包含间距。悬浮或打开时连续平移和缩放；导航滚动时根据菜单项相对滚动容器的位置更新。离开一级导航和 Mega Menu 约 `200ms` 后收回。

## Mega Menu

Mega Menu 从 Header 底部展开，背景铺满视口，内部与 Header 使用同一 `site-container`。Category 左边缘与 Logo 对齐，内容右边缘与工具区对齐。默认磨砂参数：

```css
background: rgb(255 255 255 / 82%);
backdrop-filter: blur(28px) saturate(120%);
-webkit-backdrop-filter: blur(28px) saturate(120%);
```

页面内容上方、Mega Menu 下方增加 7% 黑色遮罩。遮罩不覆盖 Header 或 Mega Menu，也不锁定桌面页面滚动。点击遮罩立即关闭菜单。

Mega Menu 最大高度为 `min(70dvh, 42rem)`，整个面板只有一个纵向滚动容器。Category、产品网格和其他 Block 不创建独立纵向滚动区。面板使用低对比度 `4–6px` 细滚动条，鼠标进入时略微加深。

面板滚动到底后继续向下滚动，页面在磨砂层后方自然向下移动；到顶后继续向上滚动，页面自然向上移动。页面滚动不关闭 Mega Menu。鼠标仍在一级导航或面板内时保持打开；离开两者约 `200ms` 后关闭。键盘焦点仍在导航或 Mega Menu 内时，不因鼠标离开关闭。

菜单关闭时，首次悬浮带下拉内容的一级菜单约 `100ms` 后打开。Mega Menu 已打开后，在一级菜单之间移动时立即切换，面板外框、Header 与遮罩保持不动。面板高度约 `220ms` 平滑变化，内部内容约 `160ms` 淡入并轻移 `4px`。切换到直接链接时延迟约 `200ms` 关闭。

首次打开使用约 `220ms` 的淡入与 `translateY(-6px)`；关闭约 `180ms`。遮罩只做透明度过渡。所有动画遵循 `prefers-reduced-motion`。

## Block 排列

Block 按 Payload 运营配置顺序纵向排列。相邻主要 Block 保留 `32–40px` 间距和低对比度分隔线。多个 Link Group 可横向排列，列之间不加分隔线。Block 标题行统一为左侧标题、右侧 CTA。Block 不包装成外层卡片，也不形成卡片嵌套。

## Category Tabs

Desktop 使用左侧 Category、右侧产品网格。Category 列宽约 `180–220px`；分类项占满整列，最小高度约 `42px`。默认透明背景和普通字重；Hover 与选中使用整行浅灰背景及 `6–8px` 圆角；选中项字重 `600`。不显示箭头、边框或下划线，状态过渡约 `180ms`。

Category Hover 使用约 `100ms` 意图延迟，点击立即切换。鼠标移入产品区时保持当前分类。切换只替换产品和右上角 CTA，不关闭 Mega Menu。

Desktop 按产品数量最多的分类预留高度。当前数据为 `8 / 4 / 3 / 4`，因此以 8 张产品卡片的行数确定高度；产品较少时允许下方留白，后续 Block 不位移。Mobile 按当前分类自然展开。

Category 列在当前区块内局部 `sticky`：分类列表位于顶部，总 CTA 固定在可见列底部。进入后续 Block 后整列自然离开。若未来分类数量超过可视高度，取消 Sticky 并让整列参与 Mega Menu 整体滚动，避免嵌套滚动。

Category 总 CTA 使用完整列宽的浅灰按钮框或细描边，`6–8px` 圆角、文字居中。当前分类 CTA 位于产品网格右上角，使用紧凑描边按钮并随分类切换。两类 CTA 都不显示文字箭头。

## 产品 Card

产品 Card 使用完整浅灰容器、`6–8px` 圆角，不使用明显边框或重阴影。内部为固定 `4:3` 图片区和固定两行高度的名称区。图片和名称居中，图片使用 `object-fit: contain`，最大宽高约为媒体区域 82%。Card 内边距约 `12px 12px 14px`。

标题约 `14px`、`600` 字重、行高约 `1.35`，最多两行并截断；单行与双行标题不改变 Card 高度。产品 Card 不显示描述或箭头。Hover 时只将图片在媒体区内放大约 `1.035`，不改变布局；Mobile 不依赖 Hover。

## Card Group

标题位于左上，组 CTA 位于右上。整组限制最大宽度并居中。Desktop 四列，横向间距约 `24px`、纵向约 `16px`；Mobile 两列，极窄屏按可读性退化为一列。

图片使用 `16:9` 和 `6–8px` 圆角。标题覆盖在图片底部，仅在底部约 35% 使用渐变遮罩，不压暗整图。删除右下角箭头。Hover 只轻微放大图片，动画约 `360ms`。组 CTA 使用右上角紧凑描边按钮。

## Link Group

Link Group 左对齐。分组标题约 `12px`、`700` 字重；普通链接约 `13–14px`、常规字重。Desktop 同组链接视觉间距约 `6–8px`，点击区域最小高度 `32px`；Mobile 最小高度 `44px`。默认无背景、边框和箭头，Hover 只显示下划线。组间距明显大于组内间距，多列顶部对齐。

## Rich Card

Rich Card 是独立 Block，不与 Category 建立尺寸或组合依赖。保持当前一个 Block 一张卡片。使用自然高度、上图下文、`16:9` 图片区和 `contain` 图片。卡片使用浅灰背景及 `6–8px` 圆角；标题最多两行、描述最多三行；整张卡片可点击，不显示右下角箭头。Hover 只放大图片。Mobile 使用相同结构并自然缩放。

## CTA 层级

- Header 的 `Shop Insta360` 使用深色实心主按钮。
- Category 底部 CTA 使用整列宽度浅灰按钮框。
- 产品网格、Card Group 等标题行 CTA 使用紧凑描边按钮。
- Mega Menu 内 CTA 不显示文字箭头；Hover 只调整背景和边框颜色。

## 移动端导航

沿用当前排列：左侧汉堡、居中 Logo、右侧 Search。同一个汉堡按钮原位变形为关闭图标，第一、三条线旋转，中间线淡出，动画约 `300ms`。不增加第二个关闭按钮，三者在开合时不移动。

菜单面板位于 Header 下方，占据剩余视口高度并内部滚动；页面滚动锁定。面板为实体白色，与 Header 之间使用低对比度分隔线。一级栏目纵向排列，栏目间使用 `1px` 浅灰分隔线，最后一项可取消。

一级栏目使用同面板手风琴，同一时间只展开一个。整行可点击；有子内容的栏目使用同一个右箭头旋转，内容以约 `200ms` 的高度和透明度动画展开，箭头约 `300ms`。直接链接使用固定右箭头。

Hybrid 整行只负责展开。原一级链接以“查看全部 + 菜单名称”的独立入口放在展开内容底部，并继承原链接的 `newTab`。

Products 展开后 Category 默认全部收起，同一时间只展开一个分类。切换时前一个自动收起。关闭 Products、切换一级栏目或关闭菜单时重置 Category。

移动端产品 Card 沿用桌面内部结构并优先保持两列，间距约 `10–12px`。小于约 `360px` 时先收紧间距和内边距；只有无法保证标题可读性时才使用单列。

`Shop Insta360` 位于底部固定操作区，使用实体白色背景、顶部浅分隔线和整行深色实心按钮。内容区在其上方滚动并预留安全区。

每次关闭后重置一级栏目、Category 和滚动位置。路由变化时同样关闭并重置。焦点返回汉堡按钮。

## 键盘与焦点

- `Tab` 聚焦桌面一级菜单时显示指示线，但不自动打开 Mega Menu。
- 纯 Dropdown 使用 `Enter` 或 `Space` 打开或关闭。
- Hybrid 使用 `Enter` 跳转，使用 `ArrowDown` 打开 Mega Menu。
- Mega Menu 打开后，`Tab` 可进入 Category、Card、Link 和 CTA。
- `Escape` 关闭 Mega Menu，并把焦点还给对应一级菜单。
- 被聚焦的隐藏菜单项自动完整滚入视野。
- 移动端使用 `Enter` 或 `Space` 展开和收起；关闭菜单后焦点返回汉堡按钮。

## 验证标准

- Desktop `>1170px`：顶部透明、滚动后 90% 白色、菜单打开后状态正确。
- 一级导航单行且右侧优先；箭头边界、渐隐和键盘自动滚入视野正确。
- 指示线在横向滚动前后都与菜单项准确对齐。
- Mega Menu 的 82% 白色、28px 模糊、120% 饱和度和 7% 遮罩层级正确。
- Mega Menu 只有一个纵向滚动容器，达到上下边界后与页面自然衔接并保持打开。
- Products 的 8 张 Card 按四列两行显示，所有分类切换时区块高度稳定。
- Category Sticky、两类 CTA、产品 Card、Card Group、Link Group 和 Rich Card 符合规格。
- Mobile `≤1170px`：顶部透明，滚动或打开后实体白色；同面板手风琴、单一展开状态、固定底部 CTA、状态重置和页面滚动锁定正确。
- 键盘、焦点恢复、Escape、外部链接和 `prefers-reduced-motion` 行为正确。

## 风险控制

实现变更限定在 Header 前端组件、局部状态和 CSS。实际内容图片比例或现有数据造成视觉异常时，先记录问题，再决定是否调整内容；不通过隐式修改 Header 数据掩盖布局问题。
